## 專案經驗｜比漾百貨股份有限公司
### API Gateway：動態路由與 IP 管理
- 建置 Gateway 管理功能，支援路由新增、查詢、刪除、啟用狀態切換與刷新。
- 將路由設定持久化至 MySQL，處理資料設定與 Gateway 路由快取同步。
- 建立 IP 白名單、來源 IP 足跡、呼叫次數及登入失敗紀錄等管理功能。
- 調整 Reactive Gateway 與阻塞式 JPA 存取的執行緒隔離，並進行本機整合驗證。

### Report：報表與企業內部流程
- 涵蓋資產盤點、員工資產、預算、人事出勤、加班、銷售與會員消費分析。
- 使用 Service／Repository 分層與 `@Transactional` 管理相關資料操作。
- 處理 Excel 產製、檔案下載、UTF-8 檔名、敏感報表下載紀錄及預算審核流程。

### Surrounding：零售周邊營運服務
- 分析與轉換 POS、發票、停車折抵、會員點數、APP、電子簽到等既有功能。
- 依原有程式、SQL 及資料格式重建 API，維持介面相容性。
- 追蹤跨模組資料流與外部服務呼叫，區分本機邏輯測試與外部端到端驗證。

### Permission／Bi4Sales：銷售快報
- 建置既有 Java 銷售業績與報表模組開發環境。
- 進行程式轉換、資料結構調整、除錯，並修改及測試銷售快報同步功能。
